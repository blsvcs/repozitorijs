# Anonimizēto nolēmumu automatizēta izgūšana

Automātiska DAGR anonimizēto nolēmumu CSV lejupielāde, arhivēšana un importēšana SQLite datubāzē.

## Palaišana

```bash
python3 sync_anon_nolemumi.py
```

## GitHub Actions

Workflow automātiski palaižas katru dienu 03:15 UTC un saglabā ģenerētos datus kā artefaktu.
